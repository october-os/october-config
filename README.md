# October configuration

October configuration is the repository with all the required configuration files.

This is meant to be installed in `~/.config/october-config/` by the installer.

## What this repository contains
- `hypr`: Hyprland Lua configuration. The `user` directory is where users can put their custom configurations.
- `kitty`: Kitty configuration file.
- `pre-rendered-templates`: Pre-rendered styles for first launch.
- `pywal`: Pywal templates.
- `quickshell`: Full Quickshell configuration.
- `scripts`: Bash scripts used by the configuration.
- `styles`: Directory where all the CSS files go during use.
- `swayosd`: SwayOSD CSS file.
- `wallpapers`: Directory where the wallpapers are going.
- `wofi`: Wofi CSS file.
